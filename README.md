# Capturas de los reportes de bugs — SIE ENGINTEL

Este repositorio guarda **solo imágenes**: las capturas que acompañan a los
reportes que la gente envía desde el backoffice con el botón de la araña. El
código del sistema no está acá.

Las imágenes viven en la rama **`bug-capturas`**, una por reporte, y el issue
correspondiente las enlaza.

## ⚠️ Este repositorio es PÚBLICO

Cualquiera puede ver estas imágenes, y los buscadores pueden indexarlas.
**Borrar una no la saca de los cachés.** Eso vale tanto para quien reporta como
para quien revisa.

## Qué se envía, y qué no

La aplicación **no manda la pantalla completa**. Quien reporta encuadra un
rectángulo sobre la captura y **solo ese trozo se sube**: el recorte se copia a
una imagen nueva del tamaño del recuadro, así que los píxeles de fuera no llegan
al archivo y no hay forma de recuperarlos desde acá.

Sin encuadre no viaja imagen. El reporte se envía igual, con su contexto.

## Antes de encuadrar, mire qué queda dentro

El recorte protege lo de afuera, no lo de adentro. Deje fuera del recuadro:

- la **barra lateral y la superior**, que llevan el correo de quien está conectado;
- nombres, RUT y correos de alumnos, relatores o clientes;
- cualquier dato de una empresa que no sea el que ilustra el problema.

Si el error se ve en una fila con datos de una persona, encuadre la parte del
mensaje y descríbalo en el texto del reporte, que ése no es público.

## Si algo se publicó por error

Avise al equipo de desarrollo para borrar el archivo y el issue. Considere el
dato como ya expuesto: cambie lo que se pueda cambiar y no cuente con que el
borrado lo revierta.
